# Агент подключает навыки к хосту

Расположение и формат установки зависят от ОС, активного профиля, настроек и версии хоста. Заменяем установочные скрипты [инструкцией для агента](../hosts.md), доступной из свежего checkout. Агент определяет поддерживаемый способ подключения и настраивает один профиль окружения, затем проверяет обнаружение навыков.

Именованные профили ролей готовит `setup-agents`. Рендерер формирует файлы после того, как агент определил хост и каталог назначения.
