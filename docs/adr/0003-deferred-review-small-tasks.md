# Отложенное ревью малых задач каскада

В rr-cascade-loop-fast кодовая задача откладывает собственное Review и передаёт его покрывающему Review следующей кодовой задачи, если её worker diff — меньше 100 строк в меньшем, чем 10 файлах, без public API/schema/контрактов/migrations/test-architecture, verifier gate зелёный с первой попытки, и отложено менее трёх задач подряд. Поштучный verifier gate остаётся без изменений.

Ревью-спавны — самый дорогой расход каскада: два ревьюера на задачу. Малые низкорисковые diffs почти не дают findings, а покрывающее Review всё равно ловит их до конца каскада. Цена — findings приходят на одну задачу позже.

## Considered Options

- Opt-in по явному указанию человека: отклонено — требует решения на каждом каскаде и забывает включаться там, где выгодно.
- Батч verifier вместе с review: отклонено — verifier остаётся единственным локализатором red между задачами.
