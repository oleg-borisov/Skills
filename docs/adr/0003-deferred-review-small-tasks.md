# Отложенное ревью малых задач каскада

В rr-cascade-loop-fast малая кодовая задача может отложить Review до покрывающего Review: worker diff <100 строк и <10 файлов, без public API/schema/контрактов/migrations/test-architecture, verifier GREEN с первой попытки, задача не последняя и с последнего review отложено менее трёх кодовых задач. Carried IDs, active critical и явная user_directive требуют review сразу. Неисполняемая документация допускает отдельное отложение; каталог docs/ или расширение сами по себе не определяют безопасность.

Покрывающее Review выбирает оси по всему непокрытому диапазону каждой оси, включая отложенные задачи; tests-only последней задачи не отменяет Standards для диапазона. Последний Spec review проверяет всю spec. Это сокращает число review-вызовов без исключения обязательного покрытия; цена — более позднее обнаружение findings.

## Considered Options

- Opt-in на каждом каскаде: отклонено — требует повторного выбора там, где применимы заданные критерии.
- Батч verifier вместе с review: отклонено — отдельный verifier локализует RED между задачами и держит полные логи ошибок вне контекста implementer/reviser.
