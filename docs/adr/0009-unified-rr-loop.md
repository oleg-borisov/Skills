# Единый rr-loop для спецификации и графа задач

Граф выражает и независимые задачи, и цепочки зависимостей. Команда
`rr-loop` выбирает путь по входу: реализация одной спеки остаётся в текущем
checkout, готовый граф использует изолированные worktree. В обоих случаях
ревью охватывает результат всего плана. Для цепочки это убирает перенос
замечаний в следующий тикет, поэтому замечания ревью к ранней задаче могут
потребовать исправлений у её потребителей.

Решение заменяет промежуточное ревью каскада из [ADR-0002](0002-rr-cascade-loop-fast.md),
его отложенное ревью из [ADR-0003](0003-deferred-review-small-tasks.md) и
каскадные исключения [ADR-0005](0005-final-gate-after-review.md).
