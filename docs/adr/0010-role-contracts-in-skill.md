# Контракты ролей входят в spec-delivery

Встроенные субагенты позволяют запустить workflow сразу после установки навыка. Храним контракты ролей внутри spec-delivery и передаём каждому свежему исполнителю абсолютный путь. Полный текст передаём при подтверждённой нечитаемости пути.

Именованные профили через setup-agents указывают на тот же живой контракт и сохраняют параметры модели, reasoning effort и ограничения инструментов, которые поддерживает хост. Это убирает генерацию копий контракта и зависимость диспетча от настроек модели конкретного инструмента запуска. Универсальный тип полагается на текстовые ограничения роли. Проверки Git и handoff остаются в RR.
