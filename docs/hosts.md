# Подключение навыков к хосту

Из checkout попроси агента подключить навыки для нужного хоста, например «Подключи навыки этого репозитория для Qoder». Агент выполняет шаги ниже в текущем окружении.

1. **Определи цель.** Проверь фактические ОС, хост и его версию, настройки обнаружения навыков, переменные окружения и существующие установки. Работай с одним указанным хостом и профилем окружения. При нехватке данных сверься с официальной документацией хоста. Если после проверки остаются вопросы, без которых нельзя продолжить установку, задай их пользователю.
2. **Собери список.** Подключи названные навыки. Если пользователь не указал список, возьми все совместимые каталоги с `SKILL.md` из `skills/`. Подключай каталог целиком вместе с `references/`, `scripts/` и метаданными. Для `spec-delivery` проверь наличие Python 3.9+ и возможность запускать независимых исполнителей. Для графа нужен отдельный cwd исполнителя.
3. **Выбери способ.** Если хост обнаруживает навыки по ссылке, создай поддерживаемую ссылку на каталог в этом checkout. Если нужны обычные файлы или настоящий каталог плагина, скопируй навыки в формате хоста. Для копии сообщи, как обновлять её из checkout.
4. **Сверь состояние назначения.** Готовое подключение оставь как есть. Пользовательские файлы и ссылки на другой checkout заменяй только с отдельного согласия на конкретные пути. При миграции определи происхождение устаревших артефактов и учти приоритет путей обнаружения, чтобы старая установка не перекрывала новую. Журналы запусков в продуктовых checkout сохраняй для resume.
5. **Проверь результат.** Сверь цели ссылок или содержимое копий, затем проверь обнаружение навыков средствами выбранного хоста. Если для этого нужна новая сессия, сообщи, что уже проверено и какая проверка осталась.

## Что проверить в существующих окружениях

- **Codex и Orca.** Определи активный профиль. У аккаунтов Orca могут быть собственные каталоги обнаружения. Каждый аккаунт подключается только по запросу.
- **Qoder и Vibe.** Проверь приоритет каталогов навыков. Копия в каталоге конкретного хоста может перекрывать подключение через общий каталог. У Vibe проверь эффективное значение `VIBE_HOME`.
- **Antigravity.** Если выбран plugin и его обнаружение требует обычного каталога, проверь структуру манифеста и каталогов по версии хоста. При миграции учти старое правило `rules/AGENTS.md`, требовавшее только диспетч типа `self`.
- **Старые версии workflow.** Проверь, остались ли команды и навыки `rr-loop`, `rr-parallel-loop` или `rr-cascade-loop-fast`, а также отдельная команда `spec-delivery` из прежней установки. Обрабатывай найденные конфликты в выбранном профиле по шагу 4.

## Именованные профили

Для установки профилей ролей `spec-delivery` используй [setup-agents](../skills/setup-agents/SKILL.md). Профиль читает контракт по абсолютному пути. При переезде checkout или смене параметров профиля повтори установку.
