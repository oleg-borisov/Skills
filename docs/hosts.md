# Установка на хосты

Для запуска `spec-delivery` подключи каталог навыка целиком, включая `references/roles/` и `scripts/`. Нужны Python 3.9+ и механизм запуска свежего дочернего агента. Для графа нужно назначать исполнителю cwd отдельного worktree. Именованные профили устанавливаются отдельно через `/setup-agents` или `$setup-agents`.

## Windows

| Команда | Что подключает |
| --- | --- |
| `./link-codex.ps1` | Junction для `.agents/skills` в checkout и для `spec-delivery` / `setup-agents` в пользовательских `~/.agents`, `~/.claude`, `~/.config/opencode` и Orca account homes. Копирует адаптер `spec-delivery.md` в Claude Code/OpenCode |
| `./link-qoder.ps1` | Junction для каждого навыка в `~/.qoder/skills` |
| `./link-vibe.ps1` | Junction для каждого навыка в `$VIBE_HOME/skills` или `~/.vibe/skills` |
| `./link-gemini.ps1` | Копирует `spec-delivery` и `setup-agents` в plugin Antigravity `~/.gemini/config/plugins/serenity-agents`. После правок навыков повтори копирование |

Qoder и Vibe заменяют обычный каталог навыка junction-ом при совпадении содержимого. Если скрипт сообщает о различиях, проверь локальные файлы перед переносом.

## macOS

Запусти `./link-opencode.sh`. Он подключает навыки в `~/.agents/skills` и `~/.config/opencode/skills` и адаптер в `~/.config/opencode/commands`. Для Antigravity используй установку копированием из [справочника хостов](../skills/setup-agents/references/hosts.md#особенности-установки).

## Именованные профили

Запусти [setup-agents](../skills/setup-agents/SKILL.md) в текущем хосте. Он читает модели из имеющейся установки, показывает рекомендации, готовит профили под `.tmp/` и спрашивает согласие перед копированием. Поддерживаемые форматы, пути, Orca и совместимость старых установок описаны в [справочнике хостов](../skills/setup-agents/references/hosts.md).

Профиль читает живой контракт с диска. Повтори установку при переезде checkout или смене настроек профиля. Если оставляешь только навык, убери прежние именованные профили spec-delivery из каталога хоста, чтобы диспетчер выбрал универсальный тип. При обновлении удали только известные старые ссылки или копии команд и навыков `rr-loop`, `rr-parallel-loop`, `rr-cascade-loop-fast`. Журналы относятся к запускам в продуктовых checkout и нужны для resume.

## Проверка

- В новой сессии вызови `/spec-delivery` или `$spec-delivery`. Проверь, что хост видит все файлы навыка и запускает универсального исполнителя при отсутствии профилей.
- Для именованной установки проверь, что хост видит шесть новых файлов, а пробный исполнитель читает контракт по абсолютному пути.
- Для Codex выбирай модель primary в диалоге. Профили задают настройки дочерних агентов.
