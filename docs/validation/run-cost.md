# Цена запуска: эталонные сценарии

Дата: 2026-11-21. Решения: [ADR-0007](../adr/0007-run-without-human-stops.md), [ADR-0008](../adr/0008-no-hash-snapshot-claim.md), уточнение [ADR-0006](../adr/0006-fast-tier-and-bounded-review.md). Цель изменений — цена запуска: число запусков исполнителей и обращений контроллера к модели; время запуска — второй критерий, размер контрактов — ограничение «не расти».

## Метод

Шесть сценариев считаются по тексту контрактов: исполнители, вызовы `RR`, остановки на человека. «До» — текст на `7771085`, подсчёт чтением. «После» — тот же сценарий исполнен скриптом на новом `rr.py` во временном репозитории: handoff исполнителей подставлены вручную, реальных исполнителей, tracker и merge в parent не было. Команды Git, tracker и dispatch в счёт не входят; где изменение убирает их, это сказано отдельно.

Счёт «до»: handoff implementer/reviser — `handoff` + `verify` + `set`; reviewer — `handoff` + `review`; verifier — `handoff` + `set`; каждая остановка — два `set`; задача parallel — ещё три `set` (старт, intent, результат merge).

| Сценарий | Исполнители | Вызовы RR | Остановки |
| --- | ---: | ---: | ---: |
| 1. rr-loop без замечаний, GREEN | 4 → 4 | 14 → 7 | 1 → 0 |
| 2. rr-loop: одно critical и docs MINOR, один repair | 9 → 9 | 27 → 13 | 1 → 0 |
| 3. rr-loop: RED на gate, repair, GREEN | 8 → 8 | 23 → 11 | 1 → 0 |
| 4. cascade: код с ревью, малая отложенная, документационная последней | 8 → 8 | 31 → 16 | 2 → 0 |
| 5. parallel: A и B независимы, C после A, D после B и C, два слота | 7 → 7 | 39 → 20 | 2 → 0 |
| 6. rr-loop: сбой implementer, смена владельца | 5 → 5 | 15 → 8 | 1 → 0 |

Число исполнителей не изменилось: правила ревью и gate прежние. Вызовы RR сокращены вдвое составными командами: `handoff` сам сверяет Git и продвигает head, `review` и `gate` принимают JSON исполнителя напрямую, `integrate` выполняет merge с intent. Дополнительно в сценарии 5 ушли ручные команды захвата и четыре отдельных `git merge`, в сценарии 6 — снятие и сверка снимка правок.

## Проверка

- `python -m unittest discover -s tests` — 49 тестов на seam `rr.main(argv)` → stdout, код возврата, `state.json`: блокировка и параллельные вызовы, повтор того же handoff, типы `set`, сверка head и оси, `init` по worktrees, итерации и лимиты, вычисляемый quality, `integrate` с конфликтом и восстановлением.
- 40 раундов двух одновременных `RR review` на Windows: потерь и сбоев нет; на `7771085` тот же прогон терял одну ось в 36 раундах из 40.
- Четыре генератора профилей выполнены; `link-*` и установка на hosts не запускались.

Не проверено: реальные запуски на продукте, фактические токены и время, блокировка на macOS/Linux (ветка `fcntl` не исполнялась).
