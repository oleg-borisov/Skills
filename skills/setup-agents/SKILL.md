# Setup Agents

1. Спроси целевой хост, если он ещё не указан. Прочитай для него [пути и форматы](references/hosts.md). Уточняй каталог установки только при нескольких возможных профилях хоста или нестандартном окружении. Найди реальный каталог навыка spec-delivery на этой машине. Для Orca и скопированных навыков используй команды из checkout репозитория.
2. Запусти `python scripts/render.py options <host>` из каталога setup-agents (на macOS обычно `python3`). Python 3.9+. При другом расположении добавь `--install-dir <каталог агента>` или `--spec-delivery <каталог навыка>`. Для каждой роли покажи установленную модель, [рекомендацию](references/models.md) и выбранное умолчание. Спроси модели одним сообщением. Можно принять все умолчания или перечислить замены по ролям. Для формата без поля модели пропусти опрос.
3. Выполни `python scripts/render.py render <host>` с теми же путями и повторяемым `--model <роль>=<модель>` для замен. Покажи шесть пар `source → destination` из JSON, модели, файлы для замены и необходимые шаги миграции. Запроси явное согласие на установку в показанные пути.
4. При согласии выполни подготовку пути из справочника и скопируй только перечисленные файлы. Если файл назначения является ссылкой, замени саму ссылку обычным файлом. Сверь содержимое назначения с источником. При отказе пропусти установку. В обоих случаях удаляй только созданный каталог `stage` под `.tmp/` после окончания работы. Если копирование прервалось, сохрани каталог до завершения повторной попытки или отказа.
5. После установки сообщи, как перезагрузить реестр этого хоста. Точка проверки — свежая сессия видит роли и один пробный запуск читает контракт по указанному пути.

Для хоста вне списка найди в первоисточнике поля определения агента, способ вызова, разделение полномочий и путь установки. Подготовь шесть файлов в отдельном каталоге под `.tmp/` checkout по той же схеме и запроси согласие по шагу 3. Каждый профиль содержит имя, описание, поддерживаемые параметры хоста и инструкцию первым шагом прочитать абсолютный путь к контракту роли. При нечитаемом файле профиль требует остановки с ошибкой.
